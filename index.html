    Set up

    1 Choose the images folder

    Approved crops are saved straight into this folder. Images already in it are marked Done.

    Your browser cannot save straight into a folder. Each image will be downloaded with the correct name to your Downloads folder instead. For the best experience, use Chrome or Edge.

    2 Load the image names

    Optional: automatic names are on, so each crop is saved as page_question_figure.png (for example 3_12_1.png). To use your own names, turn it off in Settings.

    3 Open the PDF

    You can open another PDF at any time. Progress is kept.
